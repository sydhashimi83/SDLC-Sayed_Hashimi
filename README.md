# Welcome to Markdown Basics

This repository is a **learning resource** to help you understand **Markdown**, the lightweight markup language used to format text on GitHub, in README files, and many other places.

## What is Markdown?

Markdown is a simple way to format text using symbols.

## Features of Markdown

- Easy to learn  
- Lightweight  
- Used in GitHub and documentation  

## Example Formatting

**Bold text**  
*Italic text*

## Conclusion

Markdown is a simple and powerful tool for formatting text.
